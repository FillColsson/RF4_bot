# Гайд по настройке RF4 AutoFisher

## 📊 Пошаговая настройка

### Шаг 1: Подготовка игры

1. Запусти Русскую Рыбалку 4
2. Выбери локацию (рекомендуется простая, без сложного фона)
3. Выбери поплавочную ловлю
4. Переведи игру в **оконный режим** (не полноэкранный)
5. Растяни окно на весь экран так чтобы оно было **1920x1080**

**Проверка разрешения:**
```python
# На Windows нажми Win + R, введи:
# wmic desktopmonitor get screenwidth,screenheight
# Должно быть 1920x1080
```

### Шаг 2: Запуск бота и выбор области

1. Запусти бот:
   ```bash
   python main.py
   ```

2. Нажми кнопку **"🎯 Выбрать область"** в GUI

3. Нарисуй прямоугольник вокруг поплавка:
   - Кликни и перетащи мышь
   - Отпусти кнопку когда закончишь
   - Область сохранится в `config.json`

**Рекомендации:**
- ✅ Область должна быть **в 2-3 раза больше** чем поплавок
- ✅ Включи часть дна и неба для контекста
- ❌ Не включай других рыбаков и объектов

### Шаг 3: Выбор цвета поплавка

Открой `config.json` и найди:
```json
"float_color": "red"
```

Возможные цвета:
- `"red"` - красные поплавки (H: 0-10)
- `"orange"` - оранжевые (H: 5-25)
- `"yellow"` - жёлтые (H: 20-40)
- `"green"` - зелёные (H: 35-85)

**Если цвет не совпадает:**

1. Тестируй обнаружение:
   ```bash
   python test_float_detection.py
   ```

2. Смотри логи:
   ```bash
   tail -f logs/bot_*.log
   ```

3. Если не обнаруживается, попробуй соседний цвет или напиши кастомный HSV диапазон в `float_detectors.py`

### Шаг 4: Настройка чувствительности

Откройте `config.json`:

```json
{
  "bite_detection_sensitivity": 65,
  "cast_power": 75,
  "cast_delay": 1.2
}
```

**Значения:**
- `bite_detection_sensitivity` - 0-100 (%)
  - **50-60%**: Для спокойной воды, крупной рыбы
  - **65-75%**: Нормальная чувствительность
  - **80-90%**: Для мелкой рыбы, буреля

- `cast_power` - 0-100 (%)
  - **50-70%**: Для близкой дистанции
  - **75-85%**: Среднее расстояние
  - **90-100%**: Дальний забросс

- `cast_delay` - 1.0-2.0 (сек)
  - Время ожидания перед начало ловли после заброса

## 🎯 Отладка обнаружения

### Проблема: Бот не видит поплавок

**Решение 1: Проверь цвет**
```bash
python test_float_detection.py
```
- Если поплавок не выделен зелёным - неправильный цвет
- Измени `float_color` в config.json

**Решение 2: Проверь область**
- Область слишком маленькая/большая?
- Нажми кнопку выбора области снова

**Решение 3: Проверь освещение**
- Если в игре очень темно - увеличить чувствительность
- Если очень ярко - уменьшить чувствительность

### Проблема: Много ложных срабатываний

1. **Уменьши чувствительность:**
   ```json
   "bite_detection_sensitivity": 50
   ```

2. **Проверь фон:**
   - Область содержит объекты похожего цвета?
   - Изменить область обнаружения

3. **Смотри логи:**
   ```bash
   tail -f logs/bot_*.log | grep "Methods"
   ```
   - Сколько методов сработало?
   - Если 1 метод - нужна более строгая фильтрация

### Проблема: Не обнаруживает поклёвки

1. **Увеличь чувствительность:**
   ```json
   "bite_detection_sensitivity": 80
   ```

2. **Используй детектор motion:**
   ```json
   "detector_type": "motion"
   ```

3. **Включи дебаг:**
   - Запусти test_float_detection.py
   - Вручную подвигай мышку в области поплавка
   - Должна обнаружиться как "BITE DETECTED"

## 📈 Оптимизация производительности

### FPS слишком низкий

1. **Уменьшить размер захватываемой области:**
   ```json
   "detection_region": {
     "width": 300,  // было 450
     "height": 250  // было 380
   }
   ```

2. **Использовать более быстрый детектор:**
   ```json
   "detector_type": "brightness"  // вместо "hybrid"
   ```

3. **Уменьшить частоту обработки в режиме ожидания:**
   - Отредактируй `modes/float_fishing.py`, строка ~120:
   ```python
   self.update_interval = 0.1  # вместо 0.05
   ```

### CPU использование высокое

1. **Отключить optical flow:**
   ```json
   "detector_type": "brightness"
   ```

2. **Уменьшить область:**
   - Смотри выше

## 🔍 Понимание логов

```
2024-06-06 22:30:45 [INFO] Bot started in mode: float
2024-06-06 22:30:47 [INFO] State transition: IDLE → CASTING
2024-06-06 22:30:48 [INFO] Float detected at (950, 450), confidence: 0.95
2024-06-06 22:30:50 [INFO] State transition: CASTING → WAITING
2024-06-06 22:30:55 [INFO] Bite detected! Methods: color_position, motion
2024-06-06 22:30:55 [INFO] State transition: WAITING → HOOKED
2024-06-06 22:30:56 [INFO] Hooking fish...
```

**Интерпретация:**
- `State transition` - смена состояния (нормально)
- `Float detected` - поплавок найден (confidence > 0.5 это хорошо)
- `Bite detected! Methods` - поклёвка, сработали методы обнаружения
  - `color_position` - по движению
  - `motion` - по оптическому потоку
  - `area_change` - по изменению площади

## ⚠️ Частые ошибки

1. **"Float not detected"**
   - ❌ Область слишком маленькая
   - ✅ Увеличь область обнаружения

2. **"Bite detected" но рыба не подсекается**
   - ❌ Действие подсечки не отправляется в игру
   - ✅ Проверь что pydirectinput работает (запусти test в папке)
   - ✅ Проверь что окно игры в фокусе

3. **"State stuck in FIGHTING"**
   - ❌ Состояние не переходит дальше
   - ✅ Смотри логи, есть ошибка?
   - ✅ Перезагрузи бота (F7 + F6)

4. **Бот запускается но ничего не делает**
   - ❌ Область не выбрана
   - ✅ Нажми "🎯 Выбрать область"
   - ✅ Перезагрузи main.py
