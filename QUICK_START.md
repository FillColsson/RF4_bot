# Быстрый старт: Обучение бота неоднородным поплавкам

## ⚡ Самый простой способ (5 минут)

### Вариант 1: Template Matching (для неоднородных)

```bash
# Шаг 1: Собрать образцы
python utils/float_analyzer.py
# → Откроется экран
# → Нарисуй вокруг поплавка (левая кнопка мыши + перетащи)
# → Отпусти кнопку - образец сохранится
# → Повтори 3-5 раз

# Шаг 2: Активировать Template Matching
# Открой config.json и замени:
# "float_detection_method": "hybrid"
# На:
# "float_detection_method": "template_matching"

# Шаг 3: Тестировать
python test_float_detection.py
# → Должен находить поплавок (зелёная окружность)

# Шаг 4: Запустить бота
python main.py
# → F6 - запуск, F7 - остановка
```

---

## 📊 Какой метод выбрать?

```
У тебя однородный поплавок (один цвет)?
    ↓
    Нет → Используй Template Matching
    Да  → Используй Hybrid (уже установлено)
```

**Template Matching - лучший выбор для:**
- ❌ Красно-белых полосатых
- ❌ Поплавков с градиентом
- ❌ Кубиков и сложных форм
- ✅ Работает с 3+ образцами

**Hybrid - лучше для:**
- ✅ Однородных красных
- ✅ Однородных оранжевых
- ✅ Однородных жёлтых
- ✅ Однородных зелёных

---

## 🎯 Что собирает float_analyzer.py?

Когда запустишь `python utils/float_analyzer.py`:

1. **Анализирует** расцветку поплавка (HSV)
2. **Сохраняет** образцы в папку `float_samples/`
3. **Выводит** рекомендации в консоль
4. **Создаёт** шаблон `_template.png` из 3+ образцов

Пример вывода:
```
🎨 Анализ цвета (HSV):
  Hue (оттенок): Минимум: 0, Максимум: 178, Среднее: 45.3
  Saturation: Минимум: 50, Максимум: 255, Среднее: 180.5
  Value: Минимум: 50, Максимум: 255, Среднее: 220.1

💡 Рекомендации для config.json:
  "float_color": "red"
  "hue_range": "H: 0-10 или 170-180"

⚠️  Поплавок имеет неоднородную расцветку!
   Рекомендуем: "float_detection_method": "template_matching"
```

---

## 🔧 Как обновить config.json?

```json
{
  "float_detection_method": "template_matching",  // ← Измени это
  "advanced_settings": {
    "enable_template_matching": true,
    "template_path": "float_samples/_template.png"
  }
}
```

**Или остальное:**

```json
// Multi-HSV (для несколько цветов)
{
  "float_detection_method": "multi_hsv",
  "advanced_settings": {
    "multi_hsv_ranges": [
      [0, 10, 50, 255, 50, 255],      // Красный
      [170, 180, 50, 255, 50, 255],   // Красный (другой диапазон)
      [5, 25, 50, 255, 50, 255]       // Оранжевый
    ]
  }
}

// Adaptive (автоматический выбор лучшего метода)
{
  "float_detection_method": "adaptive",
  "advanced_settings": {
    "enable_adaptive_detection": true,
    "enable_template_matching": true,
    "template_path": "float_samples/_template.png"
  }
}
```

## ✅ Проверка работает ли?

```bash
# Запусти демо
python test_float_detection.py
```

Должен увидеть:
- Скриншот экрана игры
- Зелёный прямоугольник (область обнаружения)
- Зелёная окружность (найденный поплавок)
- При движении: красный текст "BITE DETECTED"

Если этого нет:
1. Проверь что область выбрана (окно "Select Region")
2. Попробуй собрать больше образцов
3. Проверь консоль на ошибки

## 📁 Структура папки float_samples/

После запуска `float_analyzer.py` создастся:

```
float_samples/
├── float_20260606_223500.png   # Образец 1
├── float_20260606_223600.png   # Образец 2
├── float_20260606_223700.png   # Образец 3
└── _template.png               # Шаблон (создаётся из 3+ образцов)
```

Шаблон автоматически создаётся когда 3+ образцов!

## 🐛 Если не работает

### Ошибка: "Float not detected"

```bash
# Проверь
1. Есть ли файл _template.png?
   ls float_samples/
   
2. Размер должен быть > 1KB
   
3. Попробуй собрать больше образцов
   python utils/float_analyzer.py
   # Повтори 5+ раз
```

### Ошибка: "Template Matching not initialized"

```bash
# Проверь config.json
"template_path": "float_samples/_template.png"
# Путь должен быть правильный
```

### Много ложных срабатываний

```bash
# Используй Multi-HSV вместо Template
# Или собери образцы в лучших условиях
```

## 💡 Советы

- **Собирай образцы в разных условиях** (спокойная/волнистая вода)

- **Если много ошибок**, собери больше образцов (5-10)
