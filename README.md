# RF4 AutoFisher - Advanced Float Fishing Bot

Универсальный автоматический бот для **Русской Рыбалки 4** с продвинутой системой распознавания поплавка и обнаружения поклёвки.

## 🎯 Возможности

### Поплавочная ловля (Float Fishing)
- ✅ **Распознавание поплавка** по цвету (красный, оранжевый, жёлтый, зелёный)
- ✅ **Обнаружение поклёвки** тремя методами:
  - Анализ движения поплавка
  - Обнаружение изменения площади поплавка
  - Оптический поток (optical flow)
- ✅ **Полный цикл ловли**: Заброс → Ожидание → Подсечка → Вываживание → Сбор
- ✅ **Рандомизированные задержки** для реалистичности
- ✅ **Система состояний** (FSM) для надёжного управления

### Архитектура
- 🏗️ **Модульная структура** - легко добавлять новые режимы ловли
- 🎮 **Унифицированный ввод** - управление мышью и клавиатурой
- 🎬 **Продвинутое компьютерное зрение** - OpenCV + детекторы
- 📊 **Логирование** - полная история действий бота
- 🖱️ **Выбор области на экране** - настройка региона обнаружения

## 🔍 Система обнаружения поклёвки

### Методы обнаружения

1. **Color + Position Detection** (`color_position`)
   - Отслеживает движение поплавка по его окраске
   - Анализирует историю позиций (последние 30 кадров)
   - Срабатывает при резких смещениях (>5 пикселей)

2. **Motion Detection** (`motion`)
   - Использует оптический поток (Farneback)
   - Анализирует общее движение в кадре
   - Порог: средняя интенсивность > 0.5

3. **Area Change Detection** (`area_change`)
   - Отслеживает площадь поплавка
   - Срабатывает при изменении на >15%
   - Полезна для погружающихся поплавков

### Гибридный детектор
- Требует активации **2 методов** из 3 для обнаружения поклёвки
- Регулируется через `bite_detection_sensitivity` (65% по умолчанию)
