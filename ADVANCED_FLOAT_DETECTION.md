# Гайд: Обучение бота распознавать сложные поплавки

## 📊 Проблема: Неоднородная расцветка

Некоторые поплавки имеют:
- Полосы (красные + белые)
- Сложные градиенты
- Несколько цветов (красная верхушка + зелёное тело)
- Нестабильный цвет из-за отражений света

**Решение**: Несколько методов обнаружения на выбор

---

## 🎯 Способ 1: Template Matching (Рекомендуется для неоднородных)

### Как это работает:
Бот "учится" узнавать поплавок по образцам вместо анализа цвета.

```
Образец поплавка (из памяти бота)
        ↓
Поиск похожего на экране (на разных масштабах)
        ↓
Найден поплавок! ✓
```

### Шаг 1: Сбор образцов

```bash
python utils/float_analyzer.py
```

Программа:
1. Откроет скриншот экрана
2. Попросит нарисовать прямоугольник вокруг поплавка
3. Сохранит образец в папку `float_samples/`
4. Выведет анализ расцветки

**Собери 3-5 образцов** в разных условиях:
- Когда поплавок спокойный
- Когда погружается
- При разном освещении
- На разной глубине

### Шаг 2: Создание шаблона

Когда образцов будет несколько (3+), программа автоматически создаст усреднённый шаблон `_template.png`.

### Шаг 3: Активация Template Matching

Отредактируй `config.json`:

```json
{
  "advanced_settings": {
    "enable_template_matching": true,
    "template_path": "float_samples/_template.png"
  }
}
```

### Шаг 4: Тестирование

```bash
python test_float_detection.py
```

Бот теперь должен находить поплавок по шаблону!

## 🔍 Способ 2: Multi-HSV (Для неоднородных с несколькими цветами)

### Как это работает:
Вместо одного диапазона цветов используем несколько.

```
Поплавок = Красные пиксели ИЛИ Оранжевые ИЛИ Жёлтые
                    ↓
Объединённая маска
                    ↓
Поплавок найден ✓
```

### Пример: Полосатый поплавок (красно-белый)

Отредактируй `core/bot.py`:

```python
from vision.advanced_detectors import MultiHSVFloatDetector

# В методе инициализации режима ловли:
hsv_ranges = [
    (0, 10, 50, 255, 50, 255),      # Красный
    (170, 180, 50, 255, 50, 255),   # Красный (другой диапазон)
    (0, 180, 0, 30, 200, 255),      # Белый (низкая насыщенность, высокая яркость)
]
self.float_detector = MultiHSVFloatDetector(hsv_ranges=hsv_ranges)
```

### Запуск анализатора для получения диапазонов:

```bash
python utils/float_analyzer.py
```

Программа выведет рекомендуемые HSV диапазоны:

```
🎨 Анализ цвета (HSV):
  Hue (оттенок):
    Минимум: 0
    Максимум: 178
    Среднее: 45.3
    Мода: 3

💡 Рекомендации для config.json:
  "float_color": "red"
  "hue_range": "H: 0-10 или 170-180"

⚠️  Поплавок имеет неоднородную расцветку!
   Рекомендуем: "float_detection_method": "template_matching"
```

## 🤖 Способ 3: Адаптивный детектор

### Как это работает:
Автоматически выбирает лучший метод:

```
Попытка Метода 1 (Color) → Если не работает
    ↓
Попытка Метода 2 (Template) → Если не работает
    ↓
Использовать лучший результат
```

### Активация:

```json
{
  "advanced_settings": {
    "enable_adaptive_detection": true,
    "enable_template_matching": true,
    "template_path": "float_samples/_template.png"
  }
}
```

## 🔧 Отладка если не работает

### Проблема: "Float not detected"

**Решение 1**: Проверь размер образца
```bash
ls -la float_samples/
# Каждый .png должен быть > 1KB
```

**Решение 2**: Попробуй Template Matching
```json
"enable_template_matching": true
```

**Решение 3**: Собери больше образцов
```bash
python utils/float_analyzer.py
# Повтори 5+ раз
```

### Проблема: "Много ложных срабатываний"

**Решение 1**: Используй Multi-HSV с узкими диапазонами

**Решение 2**: Увеличь threshold для Template Matching
```python
detector = TemplateMatchingFloatDetector(
    template_path,
    threshold=0.8  # было 0.7
)
```

### Проблема: "Медленная обработка"

**Решение 1**: Используй Color Detector вместо Template
```json
"float_detection_method": "color"
```

**Решение 2**: Уменьши область обнаружения
```json
"detection_region": {
  "width": 300,  // было 450
  "height": 250  // было 380
}
```

## 💡 Лучшие практики

1. **Собирай образцы в разных условиях**
   - При спокойной воде
   - При волнении
   - При разном времени суток
   - На разной глубине

2. **Используй Template Matching для сложных поплавков**
   - Полосы
   - Градиенты
   - Несколько цветов
   - Необычные формы

3. **Используй Color Detector для простых**
   - Однородные цвета
   - Быстрая обработка нужна
   - Уверен в цвете

4. **Комбинируй методы**
   - Используй Adaptive Detector
   - Подключи Template как резервный метод
   - Регулируй sensitivity
