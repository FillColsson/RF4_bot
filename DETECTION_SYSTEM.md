# Система обнаружения поплавка и поклёвки в RF4 AutoFisher

## 📋 Обзор

Система обнаружения состоит из нескольких компонентов:

```
Захват экрана (MSS)
        ↓
    Кроп области
        ↓
Детектор поплавка (цвет, форма)
        ↓
Анализ движения поплавка
        ↓
Обнаружение поклёвки (3 метода)
        ↓
  Подсечка (Hook)
```

## 🎯 Детектор поплавка (ColorBasedFloatDetector)

### Как работает

1. **Преобразование цветового пространства**
   ```
   BGR → HSV (для лучшего распознавания цвета)
   ```

2. **Маска по цвету**
   ```
   Использует диапазоны HSV для каждого цвета:
   - Красный: H: 0-10
   - Оранжевый: H: 5-25
   - Жёлтый: H: 20-40
   - Зелёный: H: 35-85
   ```

3. **Морфологические операции**
   ```
   Закрытие (MORPH_CLOSE) - заполнить отверстия
   Открытие (MORPH_OPEN) - убрать шум
   ```

4. **Поиск контуров**
   ```
   Находит все объекты целевого цвета
   Выбирает наибольший контур (это поплавок)
   ```

5. **Определение характеристик**
   ```
   Позиция: центр контура (x, y)
   Радиус: минимальная окружность
   Площадь: cv2.contourArea()
   Уверенность: area / 1000.0
   ```

### Пример использования

```python
from vision.float_detectors import ColorBasedFloatDetector

detector = ColorBasedFloatDetector(target_color="red")
float_info = detector.detect_float(roi)

if float_info:
    pos = float_info['position']      # (x, y)
    area = float_info['area']         # пиксели
    radius = float_info['radius']     # пиксели
    conf = float_info['confidence']   # 0-1
```

## 🔍 Обнаружение поклёвки (3 метода)

### 1. Анализ движения поплавка (Color + Position)

**Идея**: Отслеживать движение центра поплавка

**Как работает**:
1. Сохраняет историю позиций (последние 30 кадров)
2. Вычисляет расстояние между кадрами
3. Анализирует последние 3 расстояния
4. Срабатывает если: макс_расстояние > 5 пикселей И средн. > 2 пикселей

**Плюсы**:
- ✅ Быстро реагирует на движение
- ✅ Работает при разных освещениях
- ✅ Не требует сложных вычислений

**Минусы**:
- ❌ Может срабатывать на посторонний шум
- ❌ Не замечает притопленность поплавка

```python
detector = ColorBasedFloatDetector()
detector.detect_bite(frame)  # bool
```

### 2. Оптический поток (Motion Detection)

**Идея**: Анализировать движение пикселей в кадре

**Как работает**:
1. Использует алгоритм Farneback для optical flow
2. Вычисляет магнитуду движения
3. Возвращает среднее значение интенсивности
4. Срабатывает если: интенсивность > 0.5

**Плюсы**:
- ✅ Обнаруживает движение рыбы
- ✅ Работает при буреле и волнении

**Минусы**:
- ❌ Медленнее (сложные вычисления)
- ❌ Может срабатывать на тени/облака

```python
detector = MotionBasedFloatDetector()
detector.detect_bite(frame)  # bool
```

### 3. Изменение площади (Area Change Detection)

**Идея**: Поклёвка меняет видимый размер поплавка

**Как работает**:
1. Сравнивает площадь поплавка между кадрами
2. Вычисляет процент изменения
3. Срабатывает если: изменение > 15%

**Плюсы**:
- ✅ Обнаруживает притопленность поплавка
- ✅ Работает при полной неподвижности воды

**Минусы**:
- ❌ Медленнее (требует расчёта площади)
- ❌ Может срабатывать на волны

```python
detector = AreaBasedFloatDetector()
detector.detect_bite(frame, color_detector)  # bool
```

## 🔗 Гибридный детектор (HybridFloatDetector)

**Стратегия**: Требует активации 2+ методов для надёжности

```
Метод 1 (Color + Position) ✓
    +
Метод 2 (Optical Flow)     ✓
    +
Метод 3 (Area Change)      ✗
    =
Результат: ПОКЛЁВКА ОБНАРУЖЕНА ✓
```

### Регулировка чувствительности

```python
sensitivity = 0.65  # 0-1 (65%)

required_methods = max(1, int(3 * (1 - sensitivity)))

# При 65%: требуется 2 метода (3 * 0.35 = 1.05 → 2)
# При 50%: требуется 2 метода
# При 33%: требуется 2 метода
# При 0%:  требуется 1 метод (минимум)
```

## 🎮 Использование в боте

### Float Fishing

```python
class FloatFishing(FishingMode):
    def setup(self):
        # Инициализируем детектор
        float_color = self.config.get("float_color", "red")
        self.float_detector = HybridFloatDetector(
            target_color=float_color
        )
    
    def execute_cycle(self):
        # Захватываем кадр
        frame = self.vision.capture_screen()
        
        # Кропим область обнаружения
        roi = self.vision.crop_region(frame, region)
        
        # Обнаруживаем поплавок
        float_info = self.float_detector.detect_float(roi)
        
        # Если ожидаем поклёвку
        if state == WAITING:
            bite_result = self.float_detector.detect_bite(
                roi,
                sensitivity=config['bite_detection_sensitivity'] / 100.0
            )
            
            if bite_result['detected']:
                self.bite_detected = True
                self.logger.info(
                    f"Bite! Methods: {bite_result['methods']}"
                )
```

## 🔧 Оптимизация

### Если много ложных срабатываний:
1. ↑ Уменьшить `bite_detection_sensitivity` (65% → 50%)
2. Выбрать другой цвет поплавка
3. Сузить область обнаружения

### Если не обнаруживает поклёвки:
1. ↑ Увеличить `bite_detection_sensitivity` (65% → 80%)
2. Проверить что поплавок правильного цвета
3. Использовать контрастный фон (не такой же цвет как небо)

### Если медленно:
1. Уменьшить размер области обнаружения
2. Использовать детектор "motion" вместо "hybrid"
3. Уменьшить FPS обработки (0.05 → 0.1 сек)
